## TABELA NO BANCO DE DADOS

Primeiro, crie esta tabela:

```sql
CREATE TABLE comprovativos_pagamento (
  id INT PRIMARY KEY AUTO_INCREMENT,
  usuario_id INT NOT NULL,
  metodo_pagamento VARCHAR(50) NOT NULL,
  valor_pago DECIMAL(10,2) NOT NULL,
  referencia VARCHAR(100),
  observacoes TEXT,
  tipo VARCHAR(50) DEFAULT 'assinatura',
  arquivo_path VARCHAR(255) NOT NULL,
  status ENUM('pendente', 'aprovado', 'rejeitado') DEFAULT 'pendente',
  obs_admin TEXT,
  admin_responsavel VARCHAR(100),
  admin_id INT,
  data_envio DATETIME DEFAULT CURRENT_TIMESTAMP,
  data_validacao DATETIME,
  FOREIGN KEY (usuario_id) REFERENCES usuarios(id),
  INDEX idx_status (status)
);
```

## ENDPOINT 1: UPLOAD DE COMPROVATIVO (USUÁRIO)

**Rota:** `POST /api/pagamentos/comprovativo`  
**Auth:** JWT obrigatório  
**Content-Type:** multipart/form-data

**Request (FormData):**
- `comprovativo`: File (PNG, JPG, JPEG, PDF - máx 5MB)
- `metodo_pagamento`: String ("M-Pesa", "Emola", "NIB BIM", "PayPal")
- `valor_pago`: Number (ex: 150)
- `referencia`: String (opcional)
- `observacoes`: String (opcional)
- `tipo`: String (default: "assinatura")

**Response (201):**
```json
{
  "sucesso": true,
  "mensagem": "Comprovativo recebido com sucesso!",
  "comprovativo": {
    "id": 123,
    "usuario_id": 456,
    "status": "pendente"
  }
}
```

**O que fazer:**
1. Validar tipo de arquivo (PNG, JPG, JPEG, PDF)
2. Validar tamanho máximo (5MB)
3. Renomear arquivo para: `{timestamp}_{userId}_{random}.{ext}`
4. Salvar em: `/uploads/comprovativos/`
5. Inserir registro no banco
6. Retornar sucesso

**Configuração Multer:**
```javascript
const multer = require('multer');
const path = require('path');

const storage = multer.diskStorage({
  destination: 'uploads/comprovativos/',
  filename: (req, file, cb) => {
    const uniqueSuffix = Date.now() + '-' + Math.round(Math.random() * 1E9);
    cb(null, `${uniqueSuffix}_${req.user.id}${path.extname(file.originalname)}`);
  }
});

const upload = multer({
  storage: storage,
  limits: { fileSize: 5 * 1024 * 1024 },
  fileFilter: (req, file, cb) => {
    const allowed = /jpeg|jpg|png|pdf/;
    const valid = allowed.test(path.extname(file.originalname).toLowerCase());
    cb(valid ? null : new Error('Apenas PNG, JPG, PDF'), valid);
  }
});
```

**SQL:**
```sql
SELECT 
  c.*,
  u.nome as usuario_nome,
  u.email as usuario_email,
  a.nome as admin_nome
FROM comprovativos_pagamento c
LEFT JOIN usuarios u ON c.usuario_id = u.id
LEFT JOIN usuarios a ON c.admin_id = a.id
```

## ENDPOINT 3: APROVAR COMPROVATIVO (ADMIN)

**Rota:** `POST /api/pagamentos/comprovativos/:id/aprovar`  
**Auth:** JWT + Role Admin obrigatório

**Request:**
```json
{
  "obs_admin": "Comprovativo válido. Assinatura ativada." // Opcional
}
```

**Response (200):**
```json
{
  "sucesso": true,
  "mensagem": "Comprovativo aprovado com sucesso"
}
```

**O que fazer (IMPORTANTE):**
1. Verificar se comprovativo existe
2. Verificar se `status = 'pendente'` (não aprovar já processado)
3. UPDATE comprovativo:
   - `status = 'aprovado'`
   - `admin_id = req.user.id`
   - `admin_responsavel = req.user.nome`
   - `obs_admin = req.body.obs_admin`
   - `data_validacao = NOW()`
4. **ATIVAR ASSINATURA DO USUÁRIO** (ajuste conforme sua estrutura):
```sql
UPDATE usuarios 
SET assinatura_ativa = true,
    assinatura_inicio = NOW(),
    assinatura_fim = DATE_ADD(NOW(), INTERVAL 30 DAY)
WHERE id = ?
```
5. Enviar email ao usuário: "Pagamento confirmado! Assinatura ativa."
